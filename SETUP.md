# Setup Guide: Codex + VS Code + Roblox Studio Script Sync

Follow these steps if you have not used Script Sync before.

## 1. Install Roblox Studio

Install Roblox Studio from the official Roblox website and sign in with your Roblox account.

## 2. Enable HTTP Requests

In Roblox Studio:

1. Open your game/place.
2. Go to **Home → Game Settings → Security**.
3. Turn on **Allow HTTP Requests**.

## 3. Enable Studio API Services

In the same **Game Settings → Security** page, turn on **Enable Studio Access to API Services**.

This is needed for Studio testing features that use services like DataStores.

## 4. Install the Script Sync plugin

Open the Roblox Creator Store:

https://create.roblox.com/store

Search for **Script Sync** and install the plugin.

Script Sync is the one-way Studio sync workflow for this repo. Rojo is not used here.

## 5. Clone the repo locally

Clone this GitHub repo onto your computer, then open the cloned folder in VS Code.

Use Codex in VS Code to help edit scripts, ask questions, or make changes.

## 6. Create an empty baseplate in Studio

In Roblox Studio, create a new empty baseplate/place for the game.

Then run the **Script Sync** plugin and point it at the cloned repo folder.

## 7. Let Script Sync mirror the folder structure

Script Sync should mirror these folders into the matching Roblox services:

- `ReplicatedStorage/` → `ReplicatedStorage`
- `ServerScriptService/` → `ServerScriptService`
- `StarterPlayerScripts/` → `StarterPlayer > StarterPlayerScripts`

If the plugin asks how to map folders, use those service names.

## 8. Create RemoteEvents manually

In Studio, create a Folder named **Remotes** inside **ReplicatedStorage**.

Inside `ReplicatedStorage.Remotes`, create these **RemoteEvent** instances exactly as named:

1. `DailySpinResult`
2. `ProgressionUpdated`
3. `ReactionPlayed`
4. `RequestDailySpin`
5. `RequestEquipCup`
6. `RequestEquipReaction`
7. `RequestFill`
8. `RequestPoison`
9. `RequestSip`
10. `RoundResult`
11. `StateChanged`

These are listed again in `ReplicatedStorage/Remotes/README.md`.

Do not create `.model.json` files. Those were only for the old Rojo workflow.

## 9. Press Play to test

Press **Play** in Roblox Studio.

Start by checking:

- the lobby UI appears
- the central matchmaking pad exists after the map setup is complete
- the soda fountains are present or generated by the fallback builder
- cup/straw equip buttons work
- daily spin and progression do not error in Studio output

If something errors, copy the Studio Output message into Codex and ask it to help fix the script.
